# Sicherheitsmeldungen

Sicherheitslücken nicht öffentlich als Issue mit vertraulichen Details
melden. Bis zur Einrichtung eines organisationsweiten Meldekanals werden sie
vertraulich an die verantwortliche IT-/Security-Stelle gemeldet.

Keine Produktionsdaten, Tokens oder personenbezogenen Echtdaten in Issues,
Pull Requests, Tests, Logs oder KI-Prompts verwenden. Bei Verdacht auf einen
Incident: betroffene Zugangsdaten sperren, Belege sichern und den
Incident-Prozess der Organisation starten.
