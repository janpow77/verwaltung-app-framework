# Skill: Nutzer, Rollen und Rechte

Erstelle für jede Funktion eine Matrix aus Rolle, Aktion und Datenraum. Prüfe
Zugriff serverseitig und teste mindestens:

- Mandant A kann Mandant B nicht lesen.
- Ein Nutzer ohne Schreibrecht kann nicht ändern.
- Ein Entwickler kann nicht selbst freigeben.
- Ein Admin kann keine fachliche Freigabe durch bloße UI-Rechte vortäuschen.
