# ADR-003: Framework-first statt nachträglicher Landingprüfung

Eigenentwicklungen aus Fachreferaten dürfen früh beginnen, müssen aber ab dem
ersten Commit im Framework-Template liegen. Der Landingprozess bewertet später
Zweck, Daten, Rollen, Sicherheit, Datenschutz, Tests und Betriebsfähigkeit.
Damit wird Innovation ermöglicht und Schatten-IT zugleich sichtbar und
steuerbar gemacht.
